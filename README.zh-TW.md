# 魔鏡占卜 H5 小遊戲原始碼

> AI 占卜 + 周易主題 + 姻緣／財運／事業／運勢流程 + Java 後端 + H5 多平台。

## 專案是什麼

這是一個面向 H5、微信／百度／頭條等行動場景的魔鏡占卜應用原始碼。使用者從魔鏡互動或主題入口開始，提交問題、查看占卜結果、保存歷史記錄並生成分享海報。

## 主要功能

- 魔鏡占卜與互動入口。
- 姻緣、愛情相合、財運、事業及綜合運勢流程。
- 線上說明標注 DeepSeek 與 ChatGPT 對接方向。
- 使用者管理、占卜記錄、海報生成與分享。
- 微信、百度、頭條及獨立 H5 頁面形態。

## 玩法流程

1. 選擇魔鏡、姻緣、財運、事業或運勢主題。
2. 輸入問題或依頁面提示完成互動。
3. 閱讀結果與解釋。
4. 保存記錄、生成海報並分享。
